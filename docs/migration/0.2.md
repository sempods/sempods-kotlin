# Moving from 0.1.0 to 0.2

0.2 replaces the JVM client API and changes authentication contracts. Recompile consumers and
update their calls. The [client guide](../../sempods-client/README.md) describes the resulting API.

## Choose the client modules

Use one BOM version. Add the adapters only where needed:

<!-- doc-example: illustrative; release coordinates checked against settings.gradle.kts and publishedModules in build.gradle.kts -->
```kotlin
implementation(platform("org.sempods:sempods-bom:0.2.0"))
implementation("org.sempods:sempods-client")
implementation("org.sempods:sempods-client-rdf4j") // RDF4J models; Java 25+
implementation("org.sempods:sempods-client-media") // binary media; Java 21+
```

The core requires Java 21. Building this repository and running RDF4J 6 require Java 25.

## Replace the client setup

`SempodsClient`, `SempodsPodClient`, `PodWireClient` and `SempodsHttpTransport` are removed.
An installed OkHttp client supplies the transport; a session binds a pod URL and credential.

<!-- doc-example: sempods-client/src/test/kotlin/org/sempods/client/DocumentationExamplesTest.kt#install -->
```kotlin
val http = SempodsOkHttp.install(OkHttpClient.Builder()).build()
```

For example, read a public resource with `podUrl` set to the full pod URL and `resourceIri` to
its resource IRI:

<!-- doc-example: sempods-client/src/test/kotlin/org/sempods/client/DocumentationExamplesTest.kt#public-read -->
```kotlin
val session = SempodsSession(SempodsPodBase.of(podUrl))
val pod = SempodsPod(session, http)
val result = pod.resources().getText(resourceIri)
if (result.status == 200) {
  val jsonLd = checkNotNull(result.body)
  println(jsonLd)
}
```

The snippets use `org.sempods.client.*`, `okhttp3.OkHttpClient` and, for `find`, OkHttp's
`toRequestBody` and `toMediaType`. For private data, pass `SempodsRequestAuth.bearer(token)` as the
session's second argument. A missing credential means
`anonymous()`, never `bearer(null)`. `SempodsAuth` becomes `SempodsRequestAuth`; use `refreshable`
for renewal or implement the interface for custom authentication.

Wrap `pod` in `SempodsRdf4jPod(pod)` for RDF4J or `SempodsPodMedia(pod)` for media.
[Service access](../../sempods-server/docs/auth/service-clients.md#use-the-jvm-client) shows
Client Credentials with automatic token renewal.

## Move calls and check results

Core IRI arguments are strings. Writes take `SempodsWriteOptions.inContext(contextIri)`.

| Old call | 0.2 entry point |
|---|---|
| Resource CRUD | `pod.resources()` for text/bytes; `rdf.resources()` for models |
| Subject CRUD, including external IRIs | `pod.subjects()` or `rdf.subjects()` |
| Slots and edges | `pod.slots()` or `rdf.slots()` |
| `createContext(…, public, label, description)` | `pod.contexts().create(iri, SempodsContextCreate.fields().withPublic(…).withLabel(…).withDescription(…))`; `201` is the old `true`, `200` the old `false` |
| `deleteContext`, `removeContext` | `pod.contexts().delete`; `204` and `404` both return, any other status throws |
| `dumpContext` | `pod.contexts().exportTo`, or `rdf.contexts().export` into an `RDFHandler` |
| `listContexts`, `contexts()` | `rdf.contexts().listIris()` |
| `publicContexts()` | the same on an anonymous session: `SempodsRdf4jPod(SempodsPod(SempodsSession(base), http)).contexts().listIris()` |
| `sparqlSelect` | `pod.sparql().resultsJson`, the result document unchanged |
| `sparqlSelectColumn` | `checkNotNull(pod.sparql().select(...).body).column(name)`, then each term's `value` |
| `sparqlAsk`, `sparqlConstruct` | `pod.sparql().ask`; `rdf.sparql().graphModel` |
| `lastModifiedAt`, `fetchPodLastModifiedAt` | `pod.metadata().dateModified()`; on a bearer session the read is authenticated, which records it in the audit log |
| `podExists`, `exists()` | `pod.metadata().exists()`, which returns a plain `Boolean` |
| `mintServiceToken` | `SempodsPodTokens.clientCredentials`, with a `clientSecretBasic` session |
| `ServiceTokenResponse` | `SempodsTokenResponse`; `expiresIn` is a `Duration` where `expiresInSeconds` was a `Long` |
| Media operations | `SempodsPodMedia`; unknown content length is `-1`, and a media id holding `/` or `\` is refused before anything is sent |
| `dereference` | `SempodsForeignTarget` or `SempodsRdf4jForeignTarget` |

Other calls return status, headers and body in a `SempodsResponse`. Check `status` before `body`.
Read the `ETag` header instead of an old result's `etag` field. Exact outcomes live in each
operation's KDoc.

For conditional writes, use `withIfMatch(etag)` with the tag of a read selecting only the target
context. The [RDF4J example](../../sempods-client-rdf4j/README.md#read-a-model) shows this selection.
Single-edge removal takes the slot's tag; an edge has none of its own.

| Behavior to preserve | Migration |
|---|---|
| Error handling | Failures are checked `IOException`s: `SempodsStatusException` for unexpected statuses, carrying `status` and `bodyExcerpt`, and `SempodsDecodingException` for malformed bodies. SPARQL decoding no longer silently returns false or empty results. |
| Result values | The timestamp is `dateModified().body?.dateModified`: the body is null for the `404` of an unknown pod, `dateModified` for a pod never written to; SPARQL columns contain terms with `value`; `listIris()` returns RDF4J IRIs. A column the result does not declare throws; check `variables` first where the projection is built at runtime. |
| Read downscope | Build a `SempodsContextSelection.of(contexts)`. Resource, subject and slot reads take it as `SempodsReadOptions.of(selection)`; SPARQL calls take it directly, as in `pod.sparql().resultsJson(query, selection)`. `SempodsContextSelection.readable()` selects everything readable; `of(emptyList())` selects nothing, where the old empty list meant everything. |
| Context grouping | Carry `include_contexts` into `withIncludeContexts(true)`; the default is merged data. |
| Large responses | Buffered bodies are limited to 16 MiB. Page results or use `contexts().exportTo` / `sparql().graphTo`. |
| Context catalogue | The client reads RDF; stop depending on the deprecated JSON envelopes. |

Keep `publicContexts()` and formerly anonymous metadata reads on an anonymous session. A bearer
changes the catalogue's contents, and an expired bearer can fail an otherwise public request.

Foreign reads borrow no pod credential: pass one explicitly if needed. They return every HTTP
status, with no body outside 2xx. Check the status so that a `403` or `500` does not become
“resource absent”. The RDF4J foreign reader also takes the accepted formats explicitly.

`find` has no endpoint group. Send it as a request of your own; `text` is the one required
member, and `type`, `contexts`, `include_contexts` and `limit` are optional:

<!-- doc-example: sempods-client/src/test/kotlin/org/sempods/client/DocumentationExamplesTest.kt#find -->
```kotlin
val search = """{"text":"summer party","limit":10}"""
val request = SempodsRepeatable.mark(pod.session.newRequest("POST", "_system/find"))
  .header("Accept", "application/ld+json")
  .post(search.toRequestBody("application/json".toMediaType()))
  .build()
val found = SempodsExchange(pod.calls).text(request, 200)
```

The route spells a read as `POST`; without `SempodsRepeatable.mark` the client does not resend it
after a lost connection. Query-building helpers (`existsResource`, `findReferencingResources`,
`sparqlSelectStatements`) have no successor; build the query in the application.

## Preserve transport settings

When replacing `SempodsHttpTransport`, carry these settings across:

- **Outbound guard:** pass it to `SempodsOkHttp.install`; otherwise it is absent.
- **Tracing:** add `TraceparentInterceptor` before `install` if you used ambient trace context.
- **Timeouts:** `install` sets only `callTimeout`; configure connect, read and write on the OkHttp
  builder, or they fall back to OkHttp's ten seconds. A client derived with `newBuilder()` keeps
  the installed interceptors and their budget; do not install it again.
- **Concurrency:** `install` applies an admission budget by default; pass `null` where none is
  needed.
- **Bodies:** serialize Jackson trees yourself. `SempodsContent.of(source, length)` is replayable;
  `of(InputStream)` is one-shot, stays open for the caller and is never resent.

| 0.1.0 transport | 0.2 |
|---|---|
| `send`, `sendBytes`, `sendStreaming` | `SempodsExchange.text`, `.bytes`, `.stream` |
| `SempodsRequest` | `okhttp3.Request`, started with `session.newRequest` |
| `SempodsRequest.Builder.callTimeout` | a derived client: `http.newBuilder().callTimeout(...).build()` |
| `SempodsBody` | `SempodsContent`; `newRequest` supplies the empty body `PUT`, `POST` and `PATCH` need, so there is no `empty()` |
| `SempodsBody.stream(size, open)` | `SempodsContent.of(SempodsContentSource, length)`, `-1` for an unknown size |
| `SempodsStreamedResponse` | the `InputStream` handed to a `SempodsBodyReader` |
| `transport.failure` | `SempodsStatusException` |
| `urlPathSegment` | `session.newRequest(method, route, segment…)`, which refuses an empty, `.` or `..` segment and one holding `/` or `\` |
| `SempodsCallSlot` | `SempodsAsync`, whose operation cancels every call it made |
| `objectMapper`, `requiredText`, `baseWithTrailingSlash` | none; `SempodsPodBase.of` takes the base with or without the slash |

Sessions confine requests to their pod; use `SempodsForeignTarget` for another URL.
See [transport](../../sempods-client/docs/transport.md) and
[asynchronous calls](../../sempods-client/docs/client.md#asynchronous-use).

## Host administration

`SempodsControlPlaneClient(URI, adminSecret)` becomes
`SempodsControlPlaneClient(SempodsSession(SempodsPodBase.of(serverRoot), SempodsRequestAuth.bearer(adminSecret)), http)`.
Methods return `SempodsResponse` and throw the core's checked exceptions, with `status` and
`bodyExcerpt` where 0.1.0 had `statusCode` and `responseBody`. For `podExists`, test
`status != 404`. 0.1.0 accepted any 2xx; each method now accepts only what its route answers
(`201` or `200` for a creation, `204` for a removal, `200` or `404` for the existence check, `200`
for provisioning), and any other status throws.

`provisionServiceClient` adds `expectedSecretId`. Store the returned `secretId` with the secret
and `registrationId`, and send both identifiers on the next call. Missing or stale identifiers
rotate the secret while preserving the registration and grants. Matching identifiers return
`alreadyProvisioned`. Re-provisioning preserves the owner's grants and does not recreate or
demote an existing app root. Treat changed grants as the owner's decision.

Plain HTTP beyond loopback needs the explicit `reachedOverPlaintextAt` address mapping.
See [host provisioning](../../sempods-server/docs/host-provisioning.md) and the
[admin client](../../sempods-control-plane-client/README.md).

## Service and embedding changes

| Area | Required change |
|---|---|
| Jackson | Move `com.fasterxml.jackson.databind` / `.core` to `tools.jackson.databind` / `.core`. Annotations stay under `com.fasterxml.jackson.annotation`. `JsonMappers.default()` and `withMongo()` return immutable `JsonMapper`s; `newDefault()` and `newWithMongo()` are gone, so configure a copy with `rebuild()…build()`, or use `JsonMappers.strict()` for unknown-property failures. `ObjectMapperResolver` takes a `JsonMapper`. Custom serializers use `ValueSerializer` / `ValueDeserializer`. |
| JAX-RS JSON | Jackson's `jackson-jakarta-rs-json-provider` replaces `jersey-media-json-jackson` and looks up a `ContextResolver<JsonMapper>`. A resolver that still resolves an `ObjectMapper` is silently ignored, and Jersey then writes with a stock mapper. |
| JSON wire behavior | Properties follow constructor order, then alphabetical order. Trailing content after a JSON value is rejected with `400`. |
| `SempodsPodRoutes` (`sempods-commons`) | `SPARQL_QUERY`, `META_DATE_MODIFIED`, `AUTH_TOKEN`, `context(path)`, `slot(…)` and `slotValue(…)` are removed; the client's endpoint groups own those paths. The prefixes, `CONTEXTS`, `FIND`, `MEDIA`, `AUTH_OIDC_CALLBACK` and `resource(iri)` remain. |
| `BaseEndpoint.okNoContent` | Replace with the operation followed by `Response.status(204).build()`. |
| `SempodsConfig` | Recompile for the additional defaulted connection-lifetime and registration-budget parameters; the JVM constructors changed, so swapping the jar is not enough. |
| `AuthorizationCodeStore.issue` | Adds `consentGeneration`, `subjectUris`, `consentText`. Kotlin defaults remain; Java passes `null`, `Collections.emptySet()`, `null` when unused. |
| Equivalent identities | `VerifiedIdentity.alsoKnownAs` becomes `equivalentIdentities: Set<String>`; rename the `JwtIssuer.issueIdToken` argument and `LoginService` lookup accordingly. `issueIdToken` refuses an entry that is not a WebID. Set `trustsEquivalentIdentities` for trusted providers in `OidcRelyingParty`, its `discover` factory and `OidcRelyingPartyCache`; the default is false, and Java passes it explicitly because none has `@JvmOverloads`. |

The new service registration and consent flow is described in
[Service access](../../sempods-server/docs/auth/service-clients.md). It is an experimental 0.2
extension with documented specification deviations.

## Deployment order and discovery

The supplied composition has no supported upgrade path. A deployment must plan and verify its own
upgrade; these compatibility constraints apply:

1. **Replace all pod replicas together.** For pod `https://example.org/alice`, the issuer is now
   that exact URL ([`SPS-AUTH-028`](https://github.com/sempods/sempods-spec/blob/main/spec/core/auth.md#SPS-AUTH-028)), so `iss` in access tokens and session
   cookies loses its trailing slash. Discover at `…/alice/.well-known/oauth-authorization-server` or
   `https://example.org/.well-known/oauth-authorization-server/alice`; old metadata addresses under
   `/_system/auth` return `404`. Endpoint paths stay under `/_system/auth`. New pods accept old
   tokens and cookies until expiry, but old pods reject the new issuer. Stop the 0.1 replicas
   before starting 0.2 to avoid intermittent failures. A client that stored the old issuer
   discovers again from the pod base and checks the new one against it
   ([`SPS-AUTH-068`](https://github.com/sempods/sempods-spec/blob/main/spec/core/auth.md#SPS-AUTH-068)).
2. **Deploy the pod server before the identity service, or together.** `sempods-auth` replaces
   `also_known_as` with `https://schema.sempods.org/claims/equivalent-identities`, containing HTTP(S)
   WebIDs. An old pod misses these identities and can remove alias-backed app grants during repair.
   Pod session cookies stay valid.
   Update other relying parties to read the new claim; a malformed claim fails the sign-in
   ([`SPS-OIDC-016`](https://github.com/sempods/sempods-spec/blob/main/spec/modules/oidc.md#SPS-OIDC-016)).
   Hosted MCP can be deployed in either order.
